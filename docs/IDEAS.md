# Ideas ledger

One row per idea: implemented, tested, rejected or still open. Search it before proposing or testing an idea; full write-ups live in `HANDOFF_ARCHIVE.md`.

**Statuses:** Open (not tried yet) · Testing (in progress) · Adopted (in the product) · Rejected (tried, didn't help) · Superseded (adopted, later replaced) · Measured (a fact measured, nothing to change) · Parked (worth retrying, say when).

**Rules:** edit a row in place when its status changes; never delete a row; keep each row to one line; put the numbers that decided it in Result.
